# English Trainer

Веб-додаток для вивчення англійських слів і граматики після уроків. Працює в браузері, без сервера; дані зберігаються локально в IndexedDB.

## Як запустити

- Онлайн: увімкнути GitHub Pages для репозиторію (Settings → Pages → Deploy from a branch → `main`, папка `/root`) і відкрити `https://<користувач>.github.io/claude-projects/english-trainer/`. Після першого відкриття додаток працює і без інтернету, його можна встановити як програму (іконка встановлення в адресному рядку Chrome або Edge).
- Локально: відкрити `index.html` у браузері або запустити `python3 -m http.server` у цій папці й перейти на `http://localhost:8000`.

## Що вміє

- Окремі словники з назвами, згруповані в папки; теги для слів; пошук по всіх словниках.
- Новий урок: текст уроку → запит для Claude → відповідь Claude → вибір потрібних слів галочками. Слова, які вже є в словниках, позначаються.
- Додавання слів вручну або списком (копія з Excel чи Google Sheets, формат `слово ; переклад ; приклад`).
- Режими тренування: картки, вибір перекладу, вибір англійського слова, написання, мікс.
- Інтервальні повторення (алгоритм FSRS): щодня показуються лише ті слова, які пора повторити. Впізнавання слова і його написання відстежуються окремо.
- Граматика: теми з правилами, вправи з пропусками і на переклад, ті самі інтервальні повторення. Є дві готові теми: Present Perfect vs Past Simple і майбутній час.
- Озвучення слів голосом браузера.
- Резервна копія у файл JSON і відновлення з нього (так само переносяться дані на інший комп'ютер).

## Дані

Усе лежить у браузері, на якому додаток відкрито. Інший браузер або інший комп'ютер мають окрему базу. Варто регулярно зберігати копію в Налаштуваннях; головна сторінка нагадує, якщо копії не було понад тиждень.

## Структура коду

- `js/db.js` — обгортка IndexedDB
- `js/srs.js` — алгоритм повторень FSRS-4.5
- `js/study.js` — сесії тренування і типи вправ
- `js/views-words.js` — головна, словники, новий урок, вибір тренування
- `js/views-grammar.js` — граматичні теми, вправи, готові теми
- `js/app.js` — налаштування, резервні копії, маршрутизація
